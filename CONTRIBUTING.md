# Contributing

Thanks for contributing! To keep this repository secure and maintainable, please follow these guidelines:

- Create a branch for your change and open a Pull Request (PR) rather than pushing directly to the default branch.
- Include tests or a short description of manual verification steps for changes that affect behavior.
- Ensure at least one approving review from a maintainer before merging.
- Keep dependency updates to separate PRs where possible.
